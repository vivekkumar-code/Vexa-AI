# 🤖 Vexa AI

Vexa AI is a friendly AI chatbot built with Python, Streamlit, LangChain, and Hugging Face.

It can answer general questions and provides accurate Indian date, day, and time using the application system time.

## 🚀 Features

- 🤖 AI Chatbot
- 💬 Conversational chat interface
- 🧠 Hugging Face LLM integration
- 🔗 LangChain integration
- 🕒 Accurate India date and time
- 📅 Current day detection
- 💾 Chat history using SQLite
- ➕ Multiple chats
- 🔐 Secure API key handling using Streamlit Secrets
- 🌐 Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- Hugging Face
- Qwen 2.5 7B Instruct
- SQLite
- python-dotenv
